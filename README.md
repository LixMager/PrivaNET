# PrivaNET

PrivaNET es una plataforma social minimalista orientada a la privacidad. Ofrece un entorno limpio y moderno para el registro de usuarios, autenticación y la visualización de un feed interactivo de publicaciones con soporte multimedia.

## Características Principales

- **Gestión de Accesos:** Formularios integrados para inicio de sesión y registro de nuevos usuarios.
- **Feed Dinámico:** Visualización de publicaciones en tiempo real con diseño en formato de tarjetas (cards).
- **Soporte Multimedia:** Las publicaciones soportan texto, imágenes y reproductores de audio nativos.
- **Diseño Responsive y Minimalista:** Interfaz fluida adaptada a dispositivos móviles, construida bajo estándares modernos de UI/UX (CSS puro, sin frameworks pesados).

## Stack Tecnológico

- **Frontend:** HTML5, CSS3 (Grid Layout, Flexbox, variables CSS).
- **Backend/Server:** PHP (Preparado para lógica de servidor y despliegue en entornos como XAMPP/Apache).

## Instalación y Ejecución

1. Clona este repositorio dentro de la carpeta pública de tu servidor local (ej. `htdocs` en XAMPP):
   ```bash
   git clone <url-del-repositorio> PrivaNet
   ```
2. Inicia el servidor Apache.
3. Abre tu navegador y accede a:
   ```text
   http://localhost/PrivaNet/
   ```
